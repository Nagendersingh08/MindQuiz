# MindQuiz

### Challenge your Java knowledge. Test your skills. Beat your best score.

MindQuiz is an interactive Java quiz application built with React. It allows users to test their Java programming knowledge through multiple-choice questions, tricky code snippets, and a timed quiz experience. With instant feedback, score tracking, and personalized results, MindQuiz makes Java revision more engaging.

## Features

- **15 Java Questions:** Test your knowledge with conceptual and code-based questions.
- **Timed Quiz:** Complete the challenge within a 15-minute time limit.
- **Instant Feedback:** See whether your selected answer is correct or incorrect.
- **Dynamic Scoring:** Earn points based on the value assigned to each question.
- **Progress Tracking:** Track your current question and accumulated score.
- **High Score:** Keep track of your best performance during the session.
- **Personalized Results:** Receive score-based messages and character images.
- **Replay Option:** Restart the quiz and try to improve your score.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nagendersingh08/MindQuiz
   ```

2. Navigate to the project directory:

   ```bash
   cd MindQuiz
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
